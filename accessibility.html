Accessibility

Last updated: April 29, 2026

Our commitment: ParaHype is built for neurodivergent brains. Our goal is to be neuroinclusive. Accessibility isn't an afterthought — it's core to why this app exists. We believe productivity tools should adapt to how you think, not the other way around.

Built for different brains

ParaHype is designed from the ground up for people with ADHD, Autism, AuDHD, OCD, and other neurodivergent conditions. Every design decision considers cognitive accessibility alongside physical and sensory accessibility.

What we currently support

Visual accessibility

  • High contrast color scheme (light text on dark background, WCAG AA compliant)
  • Minimum text size of 10px across the app, with most body text at 13-14px
  • Color is never the only way to convey information — icons, text labels, and patterns supplement color
  • Progress bars use distinct fill patterns alongside color changes
  • Touch targets sized at minimum 44x44px for all interactive elements
  • No rapidly flashing content or auto-playing animations that can't be stopped

Motor accessibility

  • All core features accessible via tap/click — no swipe-only gestures required
  • Large touch targets on buttons and interactive elements
  • No time-limited interactions (except the optional focus timer, which is user-controlled)
  • Voice input for coach chat via speech-to-text

Cognitive accessibility

  • Simple, consistent navigation with a fixed tab bar
  • Tasks broken into small, manageable steps with time estimates
  • Visual progress indicators (progress bars, streak dots, XP counters)
  • Six buddy vibes to match different energy and communication needs
  • Daily recurring tasks that reset automatically — no need to remember to re-add them
  • Positive language throughout — no punitive messaging for incomplete tasks
  • Daily quote and word of the day for grounding and inspiration

Auditory accessibility

  • Text-to-speech with customizable voice selection
  • Mute button to disable all voice output
  • All audio content has text equivalents — nothing is audio-only
  • No background audio or music

What we're working on

  • Full screen reader (VoiceOver / TalkBack) optimization with ARIA labels
  • Keyboard navigation support for desktop users
  • Reduced motion mode for users sensitive to animation
  • High contrast mode toggle for users who need stronger contrast
  • Font size adjustment within the app
  • Multi-language support
  • Dyslexia-friendly font option (OpenDyslexic)

Standards we follow

We aim to meet WCAG 2.1 Level AA guidelines. As a small team, we're making progress toward full compliance and prioritize the most impactful accessibility improvements first.
