# ParaHype

**Your parallel hype buddy for ADHD**

A Progressive Web App (PWA) built for Loadingdrbetha Group LLC.

## Features
- AI-powered hype coach (voice + text)
- Habit tracker with streaks & XP
- Pomodoro focus timer
- Buddy system
- Reward unlocks

## Deploy
Hosted via GitHub Pages. Visit the live URL to use or install as a PWA.
